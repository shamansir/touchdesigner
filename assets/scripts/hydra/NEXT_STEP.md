# Next step

## Done in 0.2.0 (2026-10-06)

The plan from 2026-10-06 — reduce to Compiled + Image — is implemented, and not
yet run in TouchDesigner:

| # | what | where |
|---|---|---|
| 1 | Image mode generated by the compiler; `emit_frags.py`, the 52 `.frag` files and the file-synced `pixel` DAT are gone | `hydra_compile.py` `Chain(root, inline=False)` |
| 2 | Image is a render-here point: Compiled chains read its texture instead of inlining it | `inlinable()` requires Compiled |
| 3 | `main()` is one statement per value, cached by (component, coordinate) | `Chain.gen`, `Chain.let` |
| 4 | Cheap half: uniforms are `op('<rel>/<arg>')[0]`, no Python guard | `Chain.define` |
| 5 | Identical results are not reinstalled (text, uniforms, inputs, resolution) | `install`, `SIG_KEY` |
| 6 | Coordinates mode, `hydra_coords`, Seamless tiling removed; Compiled is the default | `build_hydra.py` |
| 7 | `build` and `upgrade` share one idempotent `ensure()`; old migrations dropped | `build_hydra.py` |

Also new: uniforms and Select TOPs use **relative** paths, so copying a sketch
container keeps its chains inside the copy; a boundary is always the In TOP of
the component that reads it; `_utils.glsl` moved to `hydra-utils.glsl`.

The uncommitted Seamless/Coordinates-era versions of `emit_frags.py` and the
shaders were saved as `~/tmp/hydra-pre-0.2.0-uncommitted.patch` before removal.

### Uniforms without Python (#4, bigger half)

Merge all of a chain's arguments into one CHOP and bind it as a uniform array on
the GLSL TOP's Arrays page — no Python per frame at all. Needs checking in TD
first: the Arrays page parameter names, and whether one Select CHOP can take
several CHOP paths. Only worth it if `cook_report` still shows CPU time in the
uniforms after the cheap half.

### Viewer-only flag trigger

`onFlagChange` in `CHAIN_EXEC` (`build_hydra.py`) schedules on every flag change
(display, bypass, lock …). The signature check in `install` makes that cheap, but
it could filter to the viewer flag — first print what `flag` contains in this TD
build. Keep the boundary-input count in the shader header: TD sizes
`sTD2DInputs[]` at compile time and does not recompile when only the inputs
change.

### Drop the 0.2.0 migration

`LEGACY_PARS` / `LEGACY_OPS` / `_drop_legacy` in `build_hydra.py`, the `coords` →
`compiled` mapping in `_ensure_mode`, and the `hydra_coords` notice in `upgrade`
can go once `version_report` shows nothing older than 0.2.0 anywhere — including
the other `.toe` files and exported `.tox` trees.
